# Consignes

Rends-toi dans le fichier "Dockerfile". Tu vas y écrire un ensemble d'instruction afin de créer une image servie en HTTP à partir de ton application Angular. Pour cela, 2 grandes étapes : 
1. Build ton application Angular
2. Utiliser nginx pour servir ton application buildée.


## Mais avant ça...

Lance la commande `ng build`. 
- À quoi ça sert ?
- Que contient le dossier `/dist/ng-docker` ?
- Renomme ton projet Angular (donne lui le nom que tu veux)
- Relance la commande `ng build`
- Que deviens `/dist/ng-docker` ?
